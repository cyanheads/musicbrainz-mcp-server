# 0.1.7 — 2026-09-20

## Added

- **`sessionMode: 'stateless'`** declared in `createApp()` ([#13](https://github.com/cyanheads/musicbrainz-mcp-server/issues/13)) — the HTTP session posture now holds however the process is launched, rather than depending on a deployment env var; `.env.example` restates it.

## Changed

- **`@cyanheads/mcp-ts-core` `^0.12.3` → `^0.13.6`** — tool argument rejections now classify as `InvalidParams` (`-32602`) with a `reason` and a schema-derived recovery hint instead of `ValidationError`; tool error text closes with a `(reason … · not retryable)` clause; the upstream request URL no longer lands on client-facing `error.data` by default.
- **README reorganized** around a capability-reference structure; `.claude-plugin/plugin.json` gains `$schema` and `keywords`, and `manifest.json` author identity syncs to `cyanheads`.
- Framework skill tree moved from `skills/` to `framework-skills/` — Claude Code and Codex auto-load a plugin's root `skills/`, which was surfacing development-only skills to every installing agent. CodeQL static analysis workflow added.

## Dependencies

- `@cyanheads/mcp-ts-core` `^0.12.3` → `^0.13.6`
- `zod` `^4.4.3` → `^4.6.5`
- `@biomejs/biome` `2.5.9` → `2.5.14`, `@types/node` `26.2.0` → `26.6.1`, `ignore` `^7.0.6` → `^7.0.9`, `tsc-alias` `^1.9.2` → `^1.9.5`
