# 0.1.0 — 2026-06-13

Open music metadata over the live MusicBrainz Web Service v2 and the Cover Art Archive. Keyless, read-only, CC0 core data.

## Added

- **`musicbrainz_search_entities`** — full-text Lucene search across artist, release-group, release, recording, work, or label; returns ranked MBID + name + 0–100 relevance score. The first step when starting from a name.
- **`musicbrainz_get_artist`** — artist profile: type, country, life span, aliases, tags/genres, discography (release-groups), band-membership relationships, and external links (Wikidata/Discogs url-rels).
- **`musicbrainz_get_release_group`** — release-group: primary/secondary type, first-release date, artist credit, editions, tags, cover-art availability stub.
- **`musicbrainz_get_release`** — one edition: tracklist (media → tracks → recordings), label + catalog number, barcode, packaging, text representation, cover-art stub.
- **`musicbrainz_get_recording`** — recording: length, artist credits, ISRCs, releases it appears on, work-rels, and performance/production relationships.
- **`musicbrainz_get_work`** — work (composition): type, languages, ISWCs, writer/composer relationships, recordings that perform it.
- **`musicbrainz_get_label`** — label: type, country, life span, label code, area, aliases, tags, external links.
- **`musicbrainz_lookup_identifier`** — resolve ISRC → recordings, ISWC → works, barcode → releases. Output is a discriminated union on the resolved entity type.
- **`musicbrainz_browse_entities`** — paginate the COMPLETE linked set (every release on a label, every recording of a work) with deep offset and a true total — the complete-enumeration path past the get_* tools' one-page `inc` cap.
- **`musicbrainz_get_cover_art`** — Cover Art Archive images for a release or release-group: front/back flags, types, full URLs, and 250/500/1200px thumbnails. No art returns an empty set, not an error.
- **`musicbrainz://{entity_type}/{mbid}`** resource — a single entity by type and MBID, mirroring the get_* lookups with default `inc` sets.
- **`musicbrainz-service`** — owns the mandatory descriptive `User-Agent`, a process-wide ~1 req/sec rate limiter (concurrent calls serialize to stay under MusicBrainz's per-IP ceiling), a response cache keyed on the full request (`MUSICBRAINZ_CACHE_TTL`, default 24h), and `withRetry` backoff over the fetch + parse pipeline.
- **`cover-art-service`** — Cover Art Archive client; maps 404 to an empty image set, follows the release-group 307 redirect.
- Config (`src/config/server-config.ts`): `MUSICBRAINZ_CONTACT`, `MUSICBRAINZ_BASE_URL`, `MUSICBRAINZ_RATE_LIMIT_RPS`, `MUSICBRAINZ_CACHE_TTL`, `COVER_ART_BASE_URL`, plus timeout/retry tuning.
- Typed error contracts encoding the live 400-vs-404 split. MBID lookups: malformed/zero MBID → `invalid_mbid` (InvalidParams), valid-format-but-nonexistent → `entity_not_found` (NotFound). `lookup_identifier`: malformed ISRC/ISWC → `invalid_identifier`, well-formed-but-unresolved → `identifier_not_found`. `browse_entities`: missing/duplicate/malformed parent link → `invalid_link`, nonexistent parent → `entity_not_found`.
