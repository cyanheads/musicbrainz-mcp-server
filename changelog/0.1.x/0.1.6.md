# 0.1.6 — 2026-08-21

## Changed

- **`@cyanheads/mcp-ts-core` `^0.10.9` → `^0.12.3`** — adopts MCP SDK v2, the 2026 protocol revision, strict tool inputs, and the current server-side context and telemetry behavior.
- **MusicBrainz validation contracts** — upstream malformed MBIDs, links, and identifiers now surface as `ValidationError` while retaining their existing reason and recovery metadata; well-formed missing entities remain `NotFound`.
- **MusicBrainz and Cover Art services** — request context now derives from the handler context, storage receives that canonical context, and Cover Art treats an upstream 404 as an expected no-art response before retry classification.
- **Build, verification, and bundle tooling** — TypeScript typechecks both source and tests without emitting, build emission is isolated, dependency guards inspect overrides, and MCPB cleanup removes platform-native bindings alongside dependency-shipped agent docs.
- **Project metadata and contributor guidance** — package, manifest, and plugin author identity is Casey Hand; add repository attributes plus contributing, conduct, funding, and security guidance.
