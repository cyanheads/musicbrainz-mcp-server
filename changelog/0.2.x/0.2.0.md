# 0.2.0 — 2026-10-13

## Changed

- **Work relationships** retain the first 25 recording relationships in tool and resource output, preserving all other relations and disclosing exact totals and actual truncation; browse recording identities, then use `musicbrainz_get_recording` for performance details. [#10](https://github.com/cyanheads/musicbrainz-mcp-server/issues/10)
- **Release search/browse rows** move populated release status from `type` to `status`; subtype consumers for other entities continue using `type`. [#17](https://github.com/cyanheads/musicbrainz-mcp-server/issues/17)
- **Browse links** accept `releaseGroup` and `release_group` as aliases for `release-group`; unknown keys and conflicting spellings now return named `invalid_link` errors. [#20](https://github.com/cyanheads/musicbrainz-mcp-server/issues/20)
- **Instructions and descriptions** distinguish embedded pages, recording relationship slices, entity enumeration, and ordered tracks, and identify community-edited fields as data. [#18](https://github.com/cyanheads/musicbrainz-mcp-server/issues/18), [#22](https://github.com/cyanheads/musicbrainz-mcp-server/issues/22)
- **Bun runtime** 1.4.2 → 1.4.3; synchronized framework references with core 0.13.15.

## Fixed

- **Browse artist credits** are requested for releases, release-groups, and recordings. [#5](https://github.com/cyanheads/musicbrainz-mcp-server/issues/5)
- **Recording browse** accepts a release parent; use `musicbrainz_get_release` for ordered tracks and repeated recording occurrences. [#12](https://github.com/cyanheads/musicbrainz-mcp-server/issues/12)
- **MBIDs** advertise hexadecimal UUID grammar, normalize surrounding whitespace and uppercase, and reject malformed/all-zero IDs before fetch while preserving typed domain errors. [#21](https://github.com/cyanheads/musicbrainz-mcp-server/issues/21)
- **Markdown prose** renders community text literally beside server-authored structure while keeping structured values raw and URL bytes copyable. [#11](https://github.com/cyanheads/musicbrainz-mcp-server/issues/11)
- **Cover-art verification** propagates caller cancellation instead of returning degraded no-art success. [#23](https://github.com/cyanheads/musicbrainz-mcp-server/issues/23)

## Dependencies

- **@cyanheads/mcp-ts-core** ^0.13.14 → ^0.13.15.
- **@types/node** 26.6.4 → 26.6.5.
