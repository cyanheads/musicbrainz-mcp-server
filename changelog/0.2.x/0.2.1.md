# 0.2.1 — 2026-10-22

## Changed

- **Release tracklists** support whole-medium windows through `media_offset` and `media_limit` (defaults 0/20), with whole-release media/track totals and continuation guidance; release resources retain complete raw tracklists. ([#28](https://github.com/cyanheads/musicbrainz-mcp-server/issues/28))
- **Cover art** supports independent image windows through `limit` and `offset` (defaults 25/0, maximum 100), exact totals, and archive-wide `hasArt` on exhausted pages. ([#34](https://github.com/cyanheads/musicbrainz-mcp-server/issues/34))
- **Search and browse limits** above 100 clamp with a notice, log and counter; `MUSICBRAINZ_CLAMP_OVERSIZED_LIMITS=off` restores maximum-100 validation. ([#32](https://github.com/cyanheads/musicbrainz-mcp-server/issues/32))
- **Identifier lookup** normalizes printed/lowercase ISRCs and compact or punctuated ISWCs, echoing canonical values and rejecting malformed codes as `invalid_identifier`. ([#30](https://github.com/cyanheads/musicbrainz-mcp-server/issues/30))
- **Work relationships** include movements and arrangements, preserving upstream order, direction, optional `orderingKey` and `targetDisambiguation` on both output surfaces. ([#33](https://github.com/cyanheads/musicbrainz-mcp-server/issues/33))
- **Desktop bundles** omit development source, documentation, scripts and editor files.

## Fixed

- **Artist credits** retain credited names and verbatim nonempty join phrases throughout lookup, search, browse and identifier results. ([#25](https://github.com/cyanheads/musicbrainz-mcp-server/issues/25))
- **Recording release appearances** disclose complete, unknown or proven truncated pages through a shared `releaseAppearanceSummary` in tools and resources, without another upstream request. ([#26](https://github.com/cyanheads/musicbrainz-mcp-server/issues/26))
- **Pagination notices** distinguish zero totals, exhausted pages and unexpected empty pages; continuation uses actual returned rows, and search exposes its effective offset. Missing or invalid upstream totals fail instead of producing fabricated counts. ([#27](https://github.com/cyanheads/musicbrainz-mcp-server/issues/27))
- **Alias rendering** distinguishes explicit primary and non-primary state while omitting unknown state. ([#29](https://github.com/cyanheads/musicbrainz-mcp-server/issues/29))
- **Browse validation** names unsupported target/parent pairs and accepted parents without blaming valid UUIDs; residual upstream rejections retain truthful query guidance. ([#31](https://github.com/cyanheads/musicbrainz-mcp-server/issues/31))
