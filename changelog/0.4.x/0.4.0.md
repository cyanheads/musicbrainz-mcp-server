# 0.4.0 — 2026-11-21

## Added

- **Release editions** include available labels, catalog numbers, formats, track counts, barcodes, packaging, release-group IDs, and release events in search, browse, and barcode results. Release detail includes release events, and barcode lookup reports the upstream total and continuation guidance. ([#43](https://github.com/cyanheads/musicbrainz-mcp-server/issues/43))
- **Lookup relationships** include work publishers, recording phonographic copyright, and edition artist and label credits, with matching entity resource includes. ([#44](https://github.com/cyanheads/musicbrainz-mcp-server/issues/44))
- **Artist discographies** support `release_group_status=website-default` when browsing release groups by artist. ([#45](https://github.com/cyanheads/musicbrainz-mcp-server/issues/45))
- **Area search** returns ranked MBIDs and available ISO codes and parent areas. Pass the chosen MBID to browse as `link.area`. ([#46](https://github.com/cyanheads/musicbrainz-mcp-server/issues/46))
- **Artist lookup** supports opt-in release or recording credits with role filters, totals, and pagination. ([#47](https://github.com/cyanheads/musicbrainz-mcp-server/issues/47))

## Changed

- Upstream HTTP failures omit the captured response from `error.data.body` and `error.data.responseBody`.
- **Bun** requires version 1.4.4 or later. Packaging excludes the Vitest cache, and development and release scripts validate CLI arguments.

## Fixed

- **Release tracklists** nest artist credit details under their tracks within each medium. ([#48](https://github.com/cyanheads/musicbrainz-mcp-server/issues/48))
