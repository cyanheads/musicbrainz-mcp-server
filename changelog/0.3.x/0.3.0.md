# 0.3.0 — 2026-11-03

## Added

- Publish musicbrainz-guide and its query reference through MCP skill resources.
- **`get_work.attributes`** retains ordered, repeated and sparse work attributes, including musical key and society registrations, with relationships enabled or disabled. ([#38](https://github.com/cyanheads/musicbrainz-mcp-server/issues/38))
- **Search and browse metadata** includes release-group secondary types and recording first-release dates; browse adds supported type/status filters and release traversal by `track_artist`, with canonical filter echoes and continuation guidance. ([#39](https://github.com/cyanheads/musicbrainz-mcp-server/issues/39))
- **Lookup relationships** include release/release-group external links, recording-to-recording relationships and label relationships, with matching entity resource defaults. ([#40](https://github.com/cyanheads/musicbrainz-mcp-server/issues/40))
- **Artist and label identifiers** expose area MBIDs and exact IPI/ISNI strings; artists also retain available birth/formation and death/dissolution area members. Browse recovery identifies the `areaId` discovery path. ([#41](https://github.com/cyanheads/musicbrainz-mcp-server/issues/41))

## Changed

- **Skill delivery and plugins** ship the guide through npm, Docker, MCPB and plugin installs; plugin configuration forwards the MusicBrainz contact correctly and adds Agent Plugins root manifests.
- **Packaging and maintenance** synchronize framework skills, validate published skill trees and plugin manifests, preserve dependency runtime modules during bundle pruning, simplify installation docs and bug reports, and align the dependency age policy to one day.

## Fixed

- **Search pagination** shortens pages at MusicBrainz's 500-match window, stops continuations at the ceiling and returns typed recovery for offsets at or above 500 while retaining exact upstream totals. ([#36](https://github.com/cyanheads/musicbrainz-mcp-server/issues/36))
- **Release tracks** retain their own artist credits and display strings on both response surfaces without inheriting release or recording credits. ([#37](https://github.com/cyanheads/musicbrainz-mcp-server/issues/37))
